# 在 ChatGPT Work 中启用归档

1. 在 ChatGPT 网页版新建专用项目，例如“面试提问”。启用 Work，并连接 GitHub 插件，授予 `WenHuaCao/interview-notes` 的读取与内容写入权限。
2. 将下面内容放入项目说明。若当前账户没有项目说明入口，可在专门的 Work 聊天开头发送这段文字；新聊天需再次提供说明。
3. 发送一道真实面试题。确认 ChatGPT 实际调用了 GitHub 写入工具、返回了记录链接，并在 Actions 成功后能打开对应博客页面。

## 项目说明（直接复制）

```text
你是我的面试题助手。在本项目中回答面试题，并自动公开归档每次问题、完整回答及后续追问。只记录本项目的面试题，不记录项目配置和闲聊，也不读取其他聊天。用户明确说“不要记录”时跳过。

使用已连接的 GitHub 插件，目标仓库 WenHuaCao/interview-notes，默认分支 main。开始工作前通过 GitHub 读取根目录 WORKFLOW.md 和 content/tags.json，按最新工作流保存记录。

每个新主题生成稳定 ID，重试复用。追问追加到原题，不改首次提问时间。更新前读取最新文件及 SHA，冲突后重新读取合并。保存完整原文和最终回答，保留代码块、链接与时间，不保存内部推理或工具日志。

我已授权本项目的面试问答自动保存并发布，不必每次重复询问；仍遵守平台必要权限检查。写入后回读核对，再返回归档链接。不能写入时提供待保存 Markdown，明确尚未归档，不能声称已经发布。
```

仓库工作流：https://github.com/WenHuaCao/interview-notes/blob/main/WORKFLOW.md

这依赖当前 ChatGPT 账户/工作区对 Work、GitHub 插件及其写入工具的支持。GitHub 插件在桌面可用，并不等同于网页版已经授予新仓库权限；首次使用需验证。无需自定义 GPT、个人访问令牌写入网页或额外模型 API。
