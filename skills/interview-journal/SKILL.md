# 面试问答与回忆记录

先读取仓库根目录的 [WORKFLOW.md](../../WORKFLOW.md)，它是归档格式、GitHub 目标和每日整理规则的唯一说明；实际写入前读取当前记录及标签字典。

- 回答模式：完成用户的面试题解释，随后保存完整原题与最终回答。同主题追问追加到原记录。用户已授权在此工作流中自动公开归档；明确要求不记录时跳过，平台必要权限仍适用。
- 整理模式：按工作流只整理新增或有追问的真实记录，归并同义标签并保留人工固定标签，不改写问答正文和首次提问时间。
- 优先使用已有 GitHub 插件创建/更新文件并检查 SHA；本地可运行仓库的 `scripts/journal.mjs`。工具不可用时交付待归档 Markdown，并明确尚未保存，不能声称已经发布。
- 重试复用题目与追问 ID；回读成功后才确认归档。不要把本技能当作监听器，也不要从无关聊天中提取数据。

本技能保存在普通仓库目录，Codex 由根目录 `AGENTS.md` 指向这里。ChatGPT Work 的云端聊天由项目初始化提示词读取远程 `WORKFLOW.md`，无需访问用户本机。
